# Test Strategy

Required suites:

- Schema and protocol conformance.
- Policy allow/ask/deny/indeterminate invariants.
- Target containment, symlink, junction, and path canonicalization.
- Approval replay, expiry, substitution, and scope-confusion attacks.
- Shell and tool-call adversarial corpus.
- Complexity, allocation, input-size, and timeout budgets.
- Property, mutation, fuzz, integration, and cross-platform tests.
- Recovery, audit redaction, concurrency, and retry behavior.
